## 🚀 Featured Projects

### 1. [Voice-Controlled House Robot](https://github.com/Ayesha-Javed7155/Voice-Controlled-House-Robot)
A PyBullet-based simulated home robot that understands voice commands, navigates a virtual house, detects predefined objects using camera-based color segmentation, and performs simulated pick-and-deliver tasks.

**Technologies:** Python, PyBullet, NumPy, OpenCV, SpeechRecognition, scikit-learn

### 2. [University Governance Consistency Checker](https://github.com/Ayesha-Javed7155/University-Governance-Consistency-Checker)
A tool for analyzing university governance clauses and identifying potentially inconsistent relationships using knowledge graphs, semantic analysis, and rule-based checks.

**Technologies:** Python, Streamlit, RDFLib, NumPy, NLP tools

### 3. [StegoLab](https://github.com/Ayesha-Javed7155/StegoLab)
An interactive application for experimenting with image and WAV audio steganography, message extraction, integrity checking, and media-distortion simulations.

**Technologies:** Python, Gradio, NumPy, Pillow, SoundFile, SciPy
